## Формула

Предмет с [аффиксом принадлежности](topic:possessive-suffixes) + **var** / **yok**: *Arabam var* — «У меня есть машина», *Arabam yok* — «У меня нет машины».

Владельца показывает аффикс. Если владельца нужно назвать, он стоит в начале в [родительном падеже](topic:genitive-in): *Ali'nin arabası var* — «У Али есть машина», *Benim arabam var* — «Машина есть у меня».

### Что выражает

- **Обладание**: *Evim var* — «У меня есть дом».
- **Родство**: *İki kardeşim var* — «У меня двое братьев и сестёр».
- **То, чем человек располагает**: *Vaktim yok* — «У меня нет времени», *Bir sorum var* — «У меня есть вопрос».

## Формы

| Владелец | Есть              | Нет               |
| -------- | ----------------- | ----------------- |
| ben      | araba**m var**    | araba**m yok**    |
| sen      | araba**n var**    | araba**n yok**    |
| o        | araba**sı var**   | araba**sı yok**   |
| biz      | araba**mız var**  | araba**mız yok**  |
| siz      | araba**nız var**  | araba**nız yok**  |
| onlar    | araba**ları var** | araba**ları yok** |

Вопрос задают [частицей mI](topic:question-particle-mi): *Araban var mı?* — «У тебя есть машина?» Короткий ответ — *Var* или *Yok*.

О прошлом говорят *vardı* и *yoktu*: *Arabam vardı* — «У меня была машина». См. [прошедшее время именного сказуемого](topic:past-copula-idi).

## Подводные камни

### Без аффикса принадлежности не обойтись

Русское «у меня есть машина» нельзя перевести слово в слово: не ~~Ben araba var~~, а *Arabam var* или *Benim arabam var*. Владельца показывает аффикс при предмете.

### arabam var и bende araba var

Аффикс принадлежности говорит, что предмет мой. [Местный падеж](topic:locative-da) говорит только, что предмет сейчас при мне: *Bende kalem var* — «У меня с собой есть ручка», и не важно чья.

### yok и değil

*Arabam yok* — «У меня нет машины». *Bu benim arabam değil* — «Это не моя машина»: слово [değil](topic:negation-degil) отрицает не наличие, а то, что машина моя.

### Глагола «иметь» нет

Обладание выражает именное предложение, а не глагол. Поэтому прошедшее время образуется так же, как при слове [var](topic:var-yok): *vardı*, *yoktu*.

## Сравнение с русским

Русский тоже обходится без глагола «иметь»: «У меня есть машина». Различие в том, где назван владелец. В русском это отдельные слова «у меня», в турецком — аффикс при самом предмете: *arabam var*, буквально «моя машина есть».
