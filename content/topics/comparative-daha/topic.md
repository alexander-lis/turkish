## Формула

Предмет + то, с чем сравнивают, + **-DAn** + **daha** + прилагательное.

*Ayşe Ali'den daha uzun* — «Айше выше Али».

- То, с чем сравнивают, стоит в [исходном падеже](topic:ablative-dan) перед прилагательным.
- Слово *daha* значит «более». Когда есть исходный падеж, его можно опустить: *Ali'den uzun*.
- Само прилагательное не изменяется.

## Формы

| Схема                               | Пример               | Перевод        |
| ----------------------------------- | -------------------- | -------------- |
| daha + прилагательное               | **daha** büyük       | больше         |
| -DAn + daha + прилагательное        | evden **daha** büyük | больше дома    |
| -DAn + прилагательное               | evden büyük          | больше дома    |
| çok daha + прилагательное           | **çok daha** büyük   | гораздо больше |
| daha az + прилагательное            | **daha az** pahalı   | менее дорогой  |
| daha çok, daha az + существительное | **daha çok** para    | больше денег   |

Так же сравнивают наречия: *daha yavaş* — «медленнее», *daha iyi* — «лучше».

Равенство выражает [послелог kadar](topic:postposition-kadar): *Ali kadar uzun* — «такой же высокий, как Али».

## Подводные камни

### Слова «чем» нет

Русское «чем» по-турецки не переводится: его работу делает исходный падеж. «Выше, чем Али» — *Ali'den daha uzun*.

### То, с чем сравнивают, стоит впереди

В русском сначала идёт прилагательное, потом предмет сравнения: «больше дома». В турецком наоборот: *evden büyük*.

### Особых форм нет

У русских «хороший» и «плохой» сравнительная степень образуется от другой основы: «лучше», «хуже». В турецком правило одно для всех: *iyi — daha iyi*, *kötü — daha kötü*.

### daha — ещё и «ещё»

После названного количества *daha* значит «ещё»: *Bir çay daha* — «Ещё один чай». Перед сказуемым оно тоже бывает «ещё»: *Daha gelmedi* — «Он ещё не пришёл». Об этом — тема [«artık, hâlâ, henüz, daha»](topic:adverbs-artik-hala).

## Сравнение с русским

- У русского прилагательного есть особая форма сравнения: «выше», «больше». Турецкое прилагательное не меняется, сравнение выражает *daha*.
- Русское сравнение без «чем» требует родительного падежа: «выше Али». Турецкий исходный падеж делает то же самое: *Ali'den uzun*.
