# Турецкий грамматический справочник

Говори о предметной области словами из [GLOSSARY.md](GLOSSARY.md): в коде, в текстах интерфейса и в контенте. У каждого термина там указаны синонимы, которые в проекте заменяем этим термином.

## Контент

Перед тем как писать или править файлы в `content/`, прочитай [content/README.md](content/README.md): там формат файлов, шаблон статьи, правила разбора по морфемам и правила карты тем.

## Проверка

- `mise run check` — линтеры, типы, тесты и проверка контента. Работа готова, когда эта команда проходит.
- `mise run content:check` — только проверка контента; печатает все ошибки с файлом и причиной.
- `mise run format` — исправляет форматирование.
- Остальные задачи показывает `mise tasks`.

Запускай инструменты через `mise run` или `mise exec --`: так берутся версии из `mise.toml`, а не из окружения оболочки.
