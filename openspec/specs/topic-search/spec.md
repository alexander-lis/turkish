# topic-search Specification

## Purpose
Позволяет читателю найти тему справочника по тому, что он помнит, — по названию явления, по аффиксу или по слову из примера и статьи — и открыть её страницу, не разыскивая тему на карте тем.

## Requirements

### Requirement: Окно поиска открывается кнопкой и сочетанием клавиш
На каждой странице окно поиска MUST открываться нажатием кнопки поиска в шапке и сочетанием Cmd+K или Ctrl+K. Сочетание MUST срабатывать при любой раскладке клавиатуры. При открытии фокус MUST стоять в поле запроса, а поле MUST быть пустым.

#### Scenario: Сочетание клавиш
- **WHEN** читатель на странице темы нажимает Ctrl+K
- **THEN** открывается окно поиска, и фокус стоит в пустом поле запроса

#### Scenario: Кнопка в шапке
- **WHEN** читатель на карте тем нажимает кнопку поиска в шапке
- **THEN** открывается то же окно поиска

#### Scenario: Русская раскладка
- **WHEN** включена русская раскладка, и читатель нажимает Cmd вместе с клавишей, на которой в латинской раскладке стоит K
- **THEN** окно поиска открывается

#### Scenario: Открыто окно темы
- **WHEN** на карте открыто окно темы, и читатель нажимает Ctrl+K
- **THEN** окно поиска открывается поверх окна темы

### Requirement: Закрытие окна поиска
Окно поиска MUST закрываться клавишей Escape, нажатием на затемнение вокруг окна и повторным нажатием сочетания, которым оно открывается. Закрытие MUST NOT менять адрес страницы. Набранный запрос MUST NOT сохраняться до следующего открытия.

#### Scenario: Escape
- **WHEN** окно поиска открыто, и читатель нажимает Escape
- **THEN** окно закрывается, а адрес страницы остаётся прежним

#### Scenario: Повторное сочетание
- **WHEN** окно поиска открыто, и читатель нажимает Cmd+K
- **THEN** окно закрывается

#### Scenario: Запрос не сохраняется
- **WHEN** читатель набрал запрос, закрыл окно и открыл его снова
- **THEN** поле запроса пусто

### Requirement: Поиск находит темы по вхождению
Поиск MUST находить тему, если запрос входит как часть текста в её название, суть, турецкий текст, перевод или примечание примера либо в текст статьи. С текстом статьи запрос MUST сравниваться без разметки Markdown: знаки выделения не разрывают слово, а адреса ссылок в поиске не участвуют.

#### Scenario: Часть слова в названии
- **WHEN** читатель вводит «датель»
- **THEN** в списке есть тема «Дательный падеж -(y)A»

#### Scenario: Слово из примера
- **WHEN** у темы есть пример «Ben de geliyorum.», и читатель вводит `geliyorum`
- **THEN** эта тема есть в списке

#### Scenario: Слово из текста статьи
- **WHEN** в статье темы есть подзаголовок «Частица не оглушается», и читатель вводит «оглушается»
- **THEN** эта тема есть в списке

#### Scenario: Выделение внутри слова
- **WHEN** в статье темы записано `kitap**lar**`, и читатель вводит `kitaplar`
- **THEN** эта тема есть в списке

#### Scenario: Адрес ссылки
- **WHEN** в статье темы есть ссылка `[гармония гласных](topic:vowel-harmony)`, а слова `vowel` в её текстах нет
- **THEN** по запросу `vowel` эта тема не находится

#### Scenario: Заглушка
- **WHEN** читатель вводит слово из сути темы-заглушки
- **THEN** заглушка есть в списке

### Requirement: Слово короче двух символов ищется только в названии
Слово запроса из одного символа MUST искаться только в названии темы. В сути, примерах и тексте статьи MUST искаться слова от двух символов.

#### Scenario: Один символ
- **WHEN** читатель вводит «я»
- **THEN** в списке только темы, в названии которых есть буква «я», и нет тем, где она встречается только в тексте

### Requirement: Регистр и диакритика не влияют на поиск
Поиск MUST NOT различать заглавные и строчные буквы, турецкие буквы с диакритикой и без неё — ç и c, ğ и g, ı и i, ö и o, ş и s, ü и u, гласные с циркумфлексом и без него — и русские «ё» и «е».

#### Scenario: Запрос без диакритики
- **WHEN** читатель вводит `cunku`
- **THEN** в списке есть тема «Союз çünkü: «потому что»»

#### Scenario: Запрос заглавными буквами
- **WHEN** читатель вводит `ÇÜNKÜ`
- **THEN** в списке есть тема «Союз çünkü: «потому что»»

#### Scenario: Циркумфлекс и «ё»
- **WHEN** читатель вводит `hala`, а затем «еще»
- **THEN** оба запроса находят тему «artık, hâlâ, henüz, daha: «уже, ещё»»

### Requirement: Формула аффикса находится по своим вариантам
Если в названии темы есть формула аффикса, поиск MUST находить тему по любому варианту, который формула описывает: заглавная буква заменяется каждым из своих звуков, часть в скобках присутствует или отсутствует, варианты через косую черту берутся по очереди. Строчная буква формулы MUST совпадать только сама с собой.

#### Scenario: Вариант гласной и согласного
- **WHEN** читатель вводит `de`, а затем `ta`
- **THEN** оба запроса находят тему «Местный падеж -DA»

#### Scenario: Часть в скобках
- **WHEN** читатель вводит `ecek`, а затем `yacak`
- **THEN** оба запроса находят тему «Будущее время -(y)AcAK»

#### Scenario: Косая черта
- **WHEN** читатель вводит `ır`, а затем `ar`
- **THEN** оба запроса находят тему «Настоящее-будущее время -(A/I)r»

#### Scenario: Строчная буква не чередуется
- **WHEN** читатель вводит `kan`
- **THEN** тема «-(y)ken: «пока, когда»» не находится по своей формуле

### Requirement: Слова запроса ищутся по отдельности
Запрос из нескольких слов MUST находить тему, если каждое его слово найдено в ней по правилам поиска — в любом порядке и в любых её текстах. Тема, в которой нет хотя бы одного слова запроса, MUST NOT находиться.

#### Scenario: Другой порядок слов
- **WHEN** читатель вводит «падеж мест»
- **THEN** в списке есть тема «Местный падеж -DA»

#### Scenario: Слова в разных текстах
- **WHEN** одно слово запроса есть только в названии темы, а другое — только в её статье
- **THEN** тема есть в списке

#### Scenario: Одного слова нет
- **WHEN** читатель вводит «местный причастие», и слова «причастие» в теме «Местный падеж -DA» нет
- **THEN** этой темы в списке нет

### Requirement: Порядок результатов по месту совпадения
Темы в списке MUST идти по месту совпадения: сначала те, у которых запрос совпал с названием, затем с сутью, затем с примерами, затем с текстом статьи. Место темы по запросу из нескольких слов MUST определять слово, которое совпало хуже остальных. При равенстве раньше MUST идти тема, которая стоит раньше в учебном маршруте.

#### Scenario: Название выше текста
- **WHEN** читатель вводит «гармония», и это слово есть в названии одной темы и только в статье другой
- **THEN** тема с этим словом в названии стоит в списке выше

#### Scenario: Учебный маршрут при равенстве
- **WHEN** читатель вводит «падеж», и слово одинаково совпало с названиями нескольких тем
- **THEN** эти темы идут в том порядке, в котором стоят в учебном маршруте

#### Scenario: Слова совпали в разных местах
- **WHEN** одно слово запроса совпало с названием темы, а другое — только с текстом её статьи
- **THEN** тема стоит среди тем, найденных по тексту статьи

### Requirement: Порядок совпадений с названием
Среди тем, у которых запрос совпал с названием, раньше MUST идти те, у которых слово названия или вариант формулы аффикса равны слову запроса, затем те, у которых они с него начинаются, затем те, у которых запрос стоит внутри слова.

#### Scenario: Формула выше начала слова
- **WHEN** читатель вводит `de`
- **THEN** тема «Местный падеж -DA» стоит выше темы «Союз ki и связки с ним: demek ki, yeter ki, öyle ki»

#### Scenario: Начало слова выше середины
- **WHEN** читатель вводит «мест», и одно название начинается со слова «Местный», а в другом есть слово «совместный»
- **THEN** первая тема стоит выше второй

### Requirement: Строка результата
Каждая найденная тема MUST занимать в списке одну строку с названием и уровнем; у заглушки MUST быть пометка «не написано». Если запрос совпал с названием, строка MUST показывать раздел темы. Иначе она MUST показывать фрагмент текста с выделенным совпадением и подпись, откуда фрагмент: суть, пример или название блока статьи. Совпадения с запросом MUST быть выделены и в названии: в обычном слове — само вхождение, а формула аффикса, найденная по своему варианту, — целиком.

#### Scenario: Совпало название
- **WHEN** читатель вводит «местный»
- **THEN** строка темы «Местный падеж -DA» показывает название, уровень A1 и раздел «Существительное»

#### Scenario: Совпал пример
- **WHEN** запрос `geliyorum` найден в примере «Ben de geliyorum.» с переводом «Я тоже иду.»
- **THEN** строка темы показывает подпись «Пример», турецкий текст с выделенным `geliyorum` и перевод

#### Scenario: Совпал блок статьи
- **WHEN** запрос «оглушается» найден в блоке «Подводные камни»
- **THEN** строка темы показывает подпись «Подводные камни» и фрагмент с выделенным словом

#### Scenario: Длинный абзац
- **WHEN** запрос найден в середине длинного абзаца статьи
- **THEN** строка показывает только часть абзаца вокруг совпадения, а не весь абзац

#### Scenario: Тема найдена в нескольких местах
- **WHEN** запрос найден и в названии темы, и в трёх её примерах
- **THEN** тема занимает в списке одну строку, и строка показывает раздел

#### Scenario: Заглушка в списке
- **WHEN** среди найденных тем есть заглушка
- **THEN** в её строке есть пометка «не написано»

#### Scenario: Выделение в названии
- **WHEN** читатель вводит «мест»
- **THEN** в названии темы «Местный падеж -DA» выделено «Мест»

#### Scenario: Выделение формулы аффикса
- **WHEN** читатель вводит `de`
- **THEN** в названии темы «Местный падеж -DA» выделена формула `-DA` целиком

#### Scenario: Название без совпадения
- **WHEN** тема найдена только по примеру
- **THEN** в её названии ничего не выделено

### Requirement: Число результатов ограничено
Список MUST показывать не больше двадцати тем. Если найдено больше, окно MUST показывать, сколько тем найдено всего.

#### Scenario: Найдено больше двадцати тем
- **WHEN** запросу соответствуют сорок тем
- **THEN** в списке первые двадцать по порядку результатов, и окно сообщает, что найдено сорок тем

### Requirement: Выбор строки с клавиатуры и мышью
Пока фокус стоит в поле запроса, стрелки вниз и вверх MUST перемещать выбор по строкам списка. Выбранная строка MUST быть визуально выделена и видна в окне. После каждого изменения запроса выбранной MUST становиться первая строка. Движение указателя мыши над строкой MUST делать её выбранной.

#### Scenario: Стрелка вниз
- **WHEN** в списке три строки, и читатель нажимает стрелку вниз
- **THEN** выбранной становится вторая строка, а фокус остаётся в поле запроса

#### Scenario: Запрос изменился
- **WHEN** выбрана третья строка, и читатель дописывает запрос
- **THEN** выбранной становится первая строка нового списка

#### Scenario: Список длиннее окна
- **WHEN** читатель стрелкой вниз доходит до строки, которая не помещается в окне
- **THEN** список прокручивается, и выбранная строка видна

#### Scenario: Указатель мыши
- **WHEN** читатель ведёт указатель мыши над четвёртой строкой
- **THEN** выбранной становится четвёртая строка

### Requirement: Переход к найденной теме
Enter на выбранной строке и нажатие на строку MUST открывать тему в окне темы на карте тем и закрывать окно поиска. Если запрос совпал с примером или с текстом блока статьи, окно темы MUST открываться на этом блоке. Каждая строка MUST быть ссылкой: Enter с клавишей Cmd или Ctrl и нажатие средней кнопкой мыши MUST открывать тему в новой вкладке.

#### Scenario: Enter по теме, найденной по названию
- **WHEN** выбрана строка темы «Местный падеж -DA», найденной по названию, и читатель нажимает Enter
- **THEN** открывается адрес `/?topic=locative-da`, окно поиска закрыто, а тема открыта в окне темы

#### Scenario: Совпадение в примере
- **WHEN** тема `particle-da` найдена по примеру, и читатель нажимает Enter на её строке
- **THEN** открывается адрес `/?topic=particle-da#block-examples`

#### Scenario: Совпадение в блоке статьи
- **WHEN** тема `particle-da` найдена по тексту блока «Подводные камни», и читатель нажимает на её строку
- **THEN** открывается адрес `/?topic=particle-da#block-pitfalls`

#### Scenario: Поиск на карте тем
- **WHEN** читатель на карте тем находит тему и нажимает Enter
- **THEN** тема открыта в окне темы поверх карты, а не отдельной страницей

#### Scenario: Поиск на странице темы
- **WHEN** читатель на странице темы находит другую тему и нажимает Enter
- **THEN** открывается карта тем с найденной темой в окне темы

#### Scenario: Поиск при открытом окне темы
- **WHEN** на карте открыто окно темы, и читатель находит другую тему и нажимает Enter
- **THEN** окно темы показывает найденную тему

#### Scenario: Новая вкладка
- **WHEN** читатель нажимает Ctrl+Enter на выбранной строке
- **THEN** карта тем с этой темой в окне темы открывается в новой вкладке, а текущая страница остаётся прежней

### Requirement: Состояния окна поиска
При пустом запросе окно MUST показывать вместо списка подсказку о том, что можно искать, с примерами запросов; нажатие на пример MUST подставлять его в поле запроса. Пока поисковый индекс загружается, окно MUST показывать индикатор загрузки, а если загрузить его не удалось — сообщение об ошибке и возможность повторить. Если по запросу ничего не найдено, окно MUST сообщать об этом.

#### Scenario: Пустой запрос
- **WHEN** читатель открыл окно поиска и ничего не ввёл
- **THEN** он видит подсказку с примерами запросов и не видит списка тем

#### Scenario: Пример из подсказки
- **WHEN** читатель нажимает в подсказке пример запроса «местный падеж»
- **THEN** пример стоит в поле запроса, фокус остаётся в поле, и список показывает найденные темы

#### Scenario: Ничего не найдено
- **WHEN** читатель вводит запрос, которого нет ни в одной теме
- **THEN** он видит сообщение «Ничего не найдено»

#### Scenario: Сервер недоступен
- **WHEN** читатель открывает окно поиска при остановленном сервере
- **THEN** он видит сообщение о том, что данные не удалось загрузить, и кнопку повторной попытки

### Requirement: Окно поиска доступно программам чтения с экрана
Поле запроса MUST быть размечено как поле со списком вариантов (`combobox`), список — как список вариантов (`listbox`), строки — как варианты (`option`). Выбранная строка MUST сообщаться через поле запроса, без переноса фокуса на строку. Число найденных тем MUST объявляться после изменения запроса.

#### Scenario: Выбранная строка
- **WHEN** читатель с программой чтения с экрана нажимает стрелку вниз
- **THEN** программа называет выбранную тему, а фокус остаётся в поле запроса

#### Scenario: Число найденных тем
- **WHEN** по запросу найдено три темы
- **THEN** программа чтения с экрана объявляет, что найдено три темы

### Requirement: Окно поиска на узком экране
На экране шириной от 360 пикселей окно поиска MUST помещаться по ширине без горизонтальной прокрутки, а список результатов MUST прокручиваться внутри окна.

#### Scenario: Поиск на телефоне
- **WHEN** читатель открывает окно поиска на экране шириной 375 пикселей и вводит запрос с десятью результатами
- **THEN** окно помещается по ширине экрана, а список прокручивается внутри него
