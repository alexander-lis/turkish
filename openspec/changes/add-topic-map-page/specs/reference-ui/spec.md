# Spec Delta

## ADDED Requirements

### Requirement: Карта тем доступна из шапки
В шапке каждой страницы MUST быть ссылка «Карта тем», которая открывает страницу карты тем. На самой странице карты ссылка MUST быть отмечена как текущая.

#### Scenario: Переход со страницы темы
- **WHEN** читатель на странице темы нажимает в шапке «Карта тем»
- **THEN** открывается страница карты тем по адресу `/map`

#### Scenario: Ссылка на странице карты
- **WHEN** читатель находится на странице карты тем
- **THEN** ссылка «Карта тем» в шапке отмечена как текущая страница

### Requirement: Ссылка на карту со страницы темы
Страница темы, включая страницу заглушки, MUST содержать ссылку «Показать на карте», которая открывает карту тем с этой темой, выбранной на ней.

#### Scenario: Переход к теме на карте
- **WHEN** читатель на странице темы `locative-da` нажимает «Показать на карте»
- **THEN** открывается адрес `/map?topic=locative-da`, и эта тема выбрана на карте

#### Scenario: Заглушка
- **WHEN** читатель открывает страницу темы-заглушки
- **THEN** на ней есть ссылка «Показать на карте»
