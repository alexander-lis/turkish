# Proposal

## Why

Нужен личный справочник по грамматике турецкого для русскоговорящего ученика уровня A1: вся теория в одном месте, темы идут в логичном порядке, ничего не пропущено, под каждой темой есть примеры. Сейчас репозиторий пуст, поэтому первым изменением строим каркас: формат контента, сервер, интерфейс и полную карту тем, на которую потом ляжет наполнение.

## What Changes

- Появляется формат контента в файлах репозитория: темы (метаданные + статья по фиксированному шаблону), структурированные примеры с разбором по морфемам, разделы, учебный маршрут, единый список обозначений.
- Появляется строгая проверка контента: ссылки на темы, порядок маршрута относительно пререквизитов и уровней, шаблон статьи, согласованность разборов. С невалидным контентом сервер не стартует; проверку можно запустить и отдельной командой.
- Появляется HTTP API только для чтения: список тем в порядке маршрута, разделы, тема целиком, обозначения, описание контракта в OpenAPI.
- Появляется веб-интерфейс на русском для компьютера и телефона: главная со списком тем по уровням, панель навигации с переключением «по маршруту / по разделам», страница темы по шаблону, страница «Обозначения».
- Появляется полная карта тем A1–B2 в виде заглушек, учебный маршрут по ней и три полностью написанные A1-темы для проверки шаблона: «Гармония гласных», «Множественное число -lAr», «Местный падеж -DA».
- Появляется окружение разработки: mise с версиями инструментов и задачами `dev`, `check` и другими.

За рамками этого изменения: остальные A1-темы (следующее изменение), прогресс изучения, поиск, аудио, упражнения и закрепление с ИИ, генерация примеров на сайте, хостинг и CI, статусы проверки тем.

## Capabilities

### New Capabilities

- `content-model`: формат хранения тем, примеров, разделов, учебного маршрута и обозначений в репозитории и правила целостности, которые система проверяет перед показом контента.
- `content-api`: HTTP API только для чтения, через который интерфейс и будущие серверные возможности получают проверенный контент.
- `reference-ui`: веб-интерфейс чтения справочника — списки тем, страница темы с примерами и разборами, страница обозначений, работа на телефоне.
- `topic-map`: какие темы обязан содержать справочник, как они нарезаны и на каком языке написаны, чтобы грамматика A1–B2 была покрыта без пропусков.

### Modified Capabilities

Нет: в проекте ещё нет ни одной спецификации.

## Impact

- **Код**: новые каталоги `backend/` (Python, FastAPI), `frontend/` (React, TypeScript), `content/` (темы и справочные файлы), `docs/` (источники карты тем); новые `mise.toml`, `.gitignore`, `CLAUDE.md`; обновляются `README.md` и `GLOSSARY.md`.
- **API**: новый публичный контракт `/api/*`; TypeScript-типы интерфейса генерируются из его OpenAPI-описания.
- **Зависимости**: mise, uv, pnpm и библиотеки бэкенда и фронтенда (перечислены в design.md).
- **Запуск**: читать справочник можно только при запущенном сервере; локально это одна команда `mise run dev`.
- **Следующие изменения**: наполнение A1 опирается на формат контента и правила `topic-map`, заданные здесь.
