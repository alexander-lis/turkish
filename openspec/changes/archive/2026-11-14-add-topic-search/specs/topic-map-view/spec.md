# Spec Delta

## ADDED Requirements

### Requirement: Окно темы открывается на блоке из адреса
Адрес карты с темой и блоком — `/?topic=<id>#block-<вид блока>` — MUST открывать окно темы, прокрученное к заголовку этого блока, как только содержимое темы загрузится. Если у темы такого блока нет, окно MUST открываться с начала. Закрытие окна и переход к другой теме по ссылке внутри него MUST убирать блок из адреса.

#### Scenario: Открытие адреса с блоком
- **WHEN** читатель открывает адрес `/?topic=particle-da#block-pitfalls`
- **THEN** окно темы открыто, и заголовок блока «Подводные камни» стоит в верхней части окна

#### Scenario: Тема уже открывалась
- **WHEN** читатель закрыл окно темы `particle-da`, а затем открывает адрес `/?topic=particle-da#block-examples`
- **THEN** окно темы открыто на блоке «Примеры»

#### Scenario: Блока у темы нет
- **WHEN** читатель открывает адрес заглушки с блоком `#block-examples`
- **THEN** окно темы открыто с начала

#### Scenario: Закрытие окна
- **WHEN** окно темы открыто по адресу с блоком, и читатель закрывает его
- **THEN** адрес страницы — `/`

#### Scenario: Переход к другой теме
- **WHEN** окно темы открыто по адресу с блоком, и читатель нажимает в нём на пререквизит
- **THEN** окно показывает пререквизит с начала, и блока в адресе нет
