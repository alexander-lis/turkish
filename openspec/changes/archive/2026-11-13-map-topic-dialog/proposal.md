# Proposal

## Why

После `add-topic-map-page` по справочнику ходят тремя путями: списком учебного маршрута на главной, панелью навигации со всеми 227 темами и картой тем. Карта показывает то же и больше, а списки отнимают место и внимание. На самой карте тема открывается в узкой панели с сутью и списками связей: чтобы прочитать статью, приходится уходить с карты и терять на ней место.

## What Changes

- **BREAKING** Карта тем становится главной и единственной страницей-входом: она открывается по адресу `/`, выбранная тема — `/?topic=<id>`. Старый адрес `/map` перенаправляет на `/` с тем же параметром темы.
- **BREAKING** Страницы учебного маршрута (бывшая главная) и панели навигации больше нет. В шапке остаётся одна ссылка — «Карта тем». Учебный маршрут остаётся в переходах «Предыдущая тема / Следующая тема» на странице темы.
- Страница «Обозначения» остаётся, но открывается только из блока «Примеры»; в шапке её нет.
- Нажатие на тему на карте открывает поверх карты большое окно темы с её содержимым: суть, место на карте, статья, примеры, «Не путать», «Связанные темы», переходы по учебному маршруту. Сверх содержимого страницы окно показывает список «Нужна для» — темы, которым эта нужна как пререквизит (решено на контрольной точке 5.3). Действий у окна два: «Развернуть» и «Закрыть».
- Ссылки на темы внутри окна открывают другую тему в том же окне и оставляют читателя на карте; кнопка браузера «Назад» возвращает к предыдущей теме.
- «Развернуть» открывает полную страницу темы. Ссылка «Карта тем» в шапке страницы темы возвращает на карту с этой темой в окне и на то же место карты. Ссылки «Показать на карте» больше нет.
- Положение и масштаб карты сохраняются в `localStorage` и восстанавливаются при возврате на карту. Вписывание в экран остаётся для первого открытия и действия «Показать всё».
- Панель темы на карте уходит: содержимое темы показывает окно, а связи темы — сама карта при наведении указателя на узел темы и при фокусе на нём.
- Вид карты: точечная сетка на фоне, вписывание без наложения на панель переключателей, название раздела в узле переносится на вторую и третью строку вместо обрезки, для чего узел раздела стал выше узла темы (решено на контрольной точке 5.3).

За рамками: поиск по карте, отметки о пройденных темах, список «Нужна для» на странице темы (его нет в ответе API; в окне темы он есть), удаление страницы «Обозначения».

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `reference-ui`: нет главной страницы с маршрутом, панели навигации и её группировок; в шапке одна ссылка «Карта тем», которая со страницы темы возвращает к этой теме на карте; страница обозначений открывается из блока «Примеры»; ссылки «Показать на карте» нет.
- `topic-map-view`: карта по адресу `/`; выбор темы открывает окно темы вместо панели; переходы внутри окна; «Развернуть»; подсветка связей при наведении и фокусе; сохранение положения карты; вписывание только при первом открытии.

## Impact

- **Интерфейс**: маршруты в `AppRoutes` (карта на `/`, перенаправление с `/map`, без `HomePage`); `Layout` без панели навигации; удаление `HomePage`, `NavPanel`, `src/lib/grouping.ts` с их тестами и `OverviewMark`, если он больше нигде не нужен; содержимое `TopicPage` выносится в общий компонент для страницы и окна; новое окно темы вместо `MapTopicPanel`; `MapPage`, `MapNodes`, `mapSettings.ts` (положение карты), `ArticleMarkdown` (адрес ссылки на тему зависит от того, где показана статья), `site.ts` (адреса карты).
- **Запросы интерфейса**: вместо `topicMapQuery` (темы и разделы одной загрузкой) — `sectionsQuery`: после удаления главной и панели список тем из `/api/topics` никто не читал, темы карта берёт из графа. `fetchTopics` удалён; сам путь `GET /api/topics` на сервере остаётся.
- **Тесты интерфейса**: заглушка `HTMLDialogElement.showModal` в `src/test/setup.ts` — jsdom её не реализует.
- **Хранилище браузера**: ключ `nav-grouping` больше не читается; добавляется ключ положения карты.
- **Документация**: `ARCHITECTURE.md` (раздел «Интерфейс»), `GLOSSARY.md`, если определение упоминает списки тем.
- **Бэкенд, API и контент** не меняются.
