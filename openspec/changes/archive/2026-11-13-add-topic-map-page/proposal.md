# Proposal

## Why

Справочник показывает темы только списками: по учебному маршруту и по разделам. Список не показывает, как темы связаны: какая открывает какую, что собрано в обзор, что с чем путают. Читатель видит 227 строк и не видит карты.

После изменения `add-topic-graph` у справочника есть граф тем с типизированными связями и запрос `GET /api/graph`. Этого достаточно, чтобы нарисовать темы связным деревом. Та же страница позже покажет, какие темы ученик прошёл.

## What Changes

- Появляется страница «Карта тем» по адресу `/map`: дерево «справочник → разделы → обзоры → темы», которое можно двигать и масштабировать.
- Тема обзора висит под обзором своего раздела. Остальные связи графа рисуются поверх дерева: пререквизиты, различения, связанные темы и связи с обзорами из других разделов.
- Нажатие на тему выбирает её: карта подсвечивает связи темы, а панель показывает суть, список связей по видам и ссылку на страницу темы.
- Читатель управляет видом: включает слои связей, оставляет нужные уровни, сворачивает разделы. Выбранные уровни и слои переживают перезагрузку.
- У выбранной темы есть адрес `/map?topic=<id>`. Страница темы получает ссылку «Показать на карте».
- В шапке каждой страницы появляется ссылка «Карта тем».
- В глоссарии определение «Карты тем» дополняется: в интерфейсе её показывает страница с тем же названием.

Изменение опирается на `add-topic-graph` и применяется после него.

За рамками: отметки о пройденных темах и ученики, база данных, поиск по карте, перетаскивание узлов и сохранение своей раскладки, печать и экспорт карты.

## Capabilities

### New Capabilities

- `topic-map-view`: страница «Карта тем» — дерево разделов, обзоров и тем со связями графа тем, выбор темы, слои связей, фильтр уровней и адрес выбранной темы.

### Modified Capabilities

- `reference-ui`: ссылка на карту тем в шапке каждой страницы и ссылка «Показать на карте» на странице темы.

## Impact

- **Интерфейс**: новая страница `MapPage` и её компоненты, новые чистые функции в `src/lib/` (дерево, раскладка, связи, настройки вида), запрос графа в `src/api/`, маршрут `/map`, шапка в `Layout`, ссылка в `TopicPage`.
- **Зависимости интерфейса**: `@xyflow/react` (React Flow) для холста с масштабом и узлами, `d3-hierarchy` для раскладки дерева. Код карты грузится отдельно от остальных страниц.
- **Тесты интерфейса**: заглушки окружения для React Flow в `src/test/setup.ts`, тестовый граф в `src/test/fixtures.ts`.
- **Документация**: `GLOSSARY.md`, `ARCHITECTURE.md`.
- **Бэкенд, API и контент** не меняются.
