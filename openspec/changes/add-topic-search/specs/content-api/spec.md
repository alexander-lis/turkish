# Spec Delta

## ADDED Requirements

### Requirement: Поисковый индекс
Запрос `GET /api/search-index` MUST возвращать все темы в порядке учебного маршрута. Для каждой темы ответ MUST содержать те же сведения, что и `GET /api/topics`, название раздела, текст блоков статьи по видам блоков и примеры: турецкий текст, перевод и примечание без служебной разметки. У заглушки списки блоков и примеров MUST быть пустыми.

#### Scenario: Все темы в порядке маршрута
- **WHEN** клиент запрашивает `GET /api/search-index`
- **THEN** ответ содержит каждую тему справочника, включая заглушки, в порядке учебного маршрута

#### Scenario: Написанная тема
- **WHEN** у темы есть блоки «Формула» и «Подводные камни» и три примера
- **THEN** в ответе у неё два блока в этом порядке, каждый со своим видом и текстом, и три примера

#### Scenario: Заглушка
- **WHEN** в справочнике есть тема-заглушка
- **THEN** в ответе у неё есть название, суть, уровень и название раздела, а списки блоков и примеров пусты

#### Scenario: Пример с выделением и примечанием
- **WHEN** у примера в контенте `tr: Ev*de*yim.`, `ru: Я *дома*.` и примечание
- **THEN** в ответе турецкий текст равен `Evdeyim.`, перевод — `Я дома.`, и примечание есть

#### Scenario: Пример без примечания
- **WHEN** у примера в контенте нет примечания
- **THEN** в ответе у этого примера примечание отсутствует

### Requirement: Текст статьи в поисковом индексе без разметки
Текст блока в поисковом индексе MUST быть разбит на строки — по одной на абзац, пункт списка, подзаголовок и строку таблицы — и MUST NOT содержать разметки Markdown: знаков выделения и зачёркивания, решёток заголовка, разделителей таблицы и адресов ссылок. Текст ссылки и зачёркнутый текст MUST оставаться.

#### Scenario: Выделение внутри слова
- **WHEN** в блоке статьи записано `kitap**lar**`
- **THEN** в тексте блока стоит слово `kitaplar`

#### Scenario: Ссылка на тему
- **WHEN** в блоке статьи есть ссылка `[гармония гласных](topic:vowel-harmony)`
- **THEN** в тексте блока есть слова «гармония гласных» и нет адреса `topic:vowel-harmony`

#### Scenario: Зачёркнутая форма
- **WHEN** в блоке статьи записано `~~kitap ta~~`
- **THEN** в тексте блока есть `kitap ta` без знаков зачёркивания

#### Scenario: Таблица
- **WHEN** в блоке статьи есть таблица с заголовком и двумя строками
- **THEN** в тексте блока три строки с содержимым ячеек и нет строки из дефисов и вертикальных черт

#### Scenario: Подзаголовок и абзац
- **WHEN** в блоке статьи за подзаголовком `### Частица не оглушается` идёт абзац
- **THEN** в тексте блока строка «Частица не оглушается» и следующая за ней строка с текстом абзаца

## MODIFIED Requirements

### Requirement: Машиночитаемое описание контракта
Сервер MUST публиковать по адресу `GET /api/openapi.json` описание API в формате OpenAPI, которое покрывает все операции и схемы их ответов.

#### Scenario: Описание доступно
- **WHEN** клиент запрашивает `GET /api/openapi.json`
- **THEN** ответ содержит документ OpenAPI с операциями `/api/topics`, `/api/topics/{id}`, `/api/sections`, `/api/notation`, `/api/graph` и `/api/search-index` и схемами их ответов
