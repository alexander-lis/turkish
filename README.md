# Турецкий грамматический справочник

Личный справочник по грамматике турецкого языка для русскоговорящего ученика: карта тем от A1 до B2, теория на русском и примеры с разбором по морфемам.

Контент хранится в файлах репозитория. Сервер на FastAPI проверяет его и отдаёт через API только для чтения, интерфейс на React показывает его в браузере на компьютере и телефоне.

## Установка

Нужен только [mise](https://mise.jdx.dev): он ставит Python, Node, uv, pnpm и hk тех версий, что записаны в `mise.toml`.

```sh
mise install        # инструменты
mise run setup      # зависимости и git-хуки
```

При первом запуске mise спросит, доверять ли файлу `mise.toml` в этом каталоге. Ответьте «да» или заранее выполните `mise trust`.

## Запуск

```sh
mise run dev
```

Команда поднимает сервер API на `http://127.0.0.1:8000` и интерфейс на `http://127.0.0.1:5173`. Если порт 5173 занят, Vite возьмёт следующий и напечатает адрес в консоли. Описание API открывается по адресу `/api/docs`.

## Задачи mise

| Задача          | Что делает                                                          |
| --------------- | ------------------------------------------------------------------- |
| `install`       | ставит зависимости: `uv sync` и `pnpm install`                      |
| `setup`         | `install` и git-хуки: pre-commit, commit-msg, pre-push              |
| `dev`           | запускает `dev:backend` и `dev:frontend` параллельно                |
| `dev:backend`   | сервер API с перезапуском при изменении кода и контента             |
| `dev:frontend`  | Vite с прокси `/api` на сервер API                                  |
| `content:check` | проверяет контент без запуска сервера и печатает все ошибки         |
| `content:words` | проверяет, что турецкие слова контента существуют                   |
| `content:stats` | печатает сводку наполнения: написанные темы, заглушки, примеры      |
| `gen:api`       | выгружает OpenAPI и генерирует TypeScript-типы интерфейса           |
| `lint`          | линтеры, форматирование, типы, слои и свежесть типов API            |
| `format`        | исправляет форматирование и автоисправляемые замечания              |
| `typecheck`     | mypy и `tsc`                                                        |
| `test`          | pytest и Vitest                                                     |
| `check`         | все проверки сразу, включая тесты и аудит зависимостей; то же — CI  |

Список проверок один — `hk.pkl`. Хуки git берут из него быстрые проверки перед коммитом, тесты перед push и проверку сообщения коммита; `check` запускает всё. Перед коммитом запускайте `mise run check`.

## Контент

Темы, примеры, разделы и учебный маршрут лежат в файлах каталога `content/`. Сервер проверяет их при старте и с ошибками не запускается; в режиме разработки он сам перезапускается после правки файла. Как писать контент, описано в [content/README.md](content/README.md).

Кроме целостности, у контента проверяются словоформы:

```sh
mise run content:words
```

Команда отдаёт каждое турецкое слово контента морфологическому анализатору и печатает слова, которых он не признаёт, вместе с файлом. Так находятся ошибки в гармонии гласных, чередованиях и написании. На запуск сервера эта проверка не влияет. Она работает на macOS и Linux.

Сколько тем уже написано, показывает сводка наполнения:

```sh
mise run content:stats
```

Она печатает для каждого уровня число тем, написанных тем и заглушек, а для каждой написанной темы — число примеров и число примеров с разбором по морфемам.

## API и типы интерфейса

Интерфейс получает контент только через API (`/api/*`). TypeScript-типы ответов лежат в `frontend/src/api/schema.d.ts` и генерируются из описания API. После изменения схем ответов в `backend/src/turkish_grammar/api/schemas.py` запустите `mise run gen:api` и закоммитьте обновлённый файл: `mise run check` падает, если он устарел.

## Устройство репозитория

| Каталог     | Что в нём                                                    |
| ----------- | ------------------------------------------------------------ |
| `backend/`  | сервер: пакет `turkish_grammar` (Python, FastAPI) и тесты    |
| `frontend/` | интерфейс (React, TypeScript, Vite, Tailwind)                |
| `content/`  | контент справочника и руководство автора                     |
| `docs/`     | источники карты тем и список исключений                      |
| `openspec/` | спецификации и изменения проекта                             |

Как устроен код, описано в [ARCHITECTURE.md](ARCHITECTURE.md), термины предметной области — в [GLOSSARY.md](GLOSSARY.md).
